# Rebrand the logo

The mark lives in **three repos**. Drop the owner's exports (rounded `logo.svg` + the square-tile
variant) into `docs-site/scripts/brand-source/`, run `cd docs-site && node scripts/generate-brand-assets.mjs`
(derives every app/docs file below, incl. PWA icons, favicon.ico and `desktop/resources/app-icon.svg`),
then `cd desktop && node resources/build-onboarding.mjs`. Copy the app's `logo*.svg`, `favicon.*`,
`apple-touch-icon.png` into the landing repo; rebuild its `logo-mark.png`/`og.png` with sharp (the old
`og.svg` renders pixel-identical to `og.png`, so regenerate from the svg). Work from the owner's export pack (`app-icon.svg`, `logo.svg`,
`logo-light.svg`, favicons, PWA icons, `SHA256SUMS.txt`). Verify the checksums, and open every SVG
first: shapes only, no `<script>`, event handlers or external `href`s.

## Every place (check each one off)

**App repo — `open-net-worth`** (commit from a clean worktree of `origin/main` if the shared
checkout is on someone else's branch)
- `frontend/public/`: `logo.svg` (tile), `logo-light.svg`, `logo-mark.svg` (mark only),
  `favicon.svg`, `favicon.ico`, `manifest.webmanifest`
- `frontend/public/icons/`: `icon-192.png`, `icon-512.png`, `icon-maskable-192.png`,
  `icon-maskable-512.png`, `apple-touch-icon.png` (inlined into `index.html` as a data: URI at
  build time by `vite.config.ts`'s `inlineAppleTouchIcon` — iOS 27 ignores a URL one; no cache-bust tag)
- Cache-bust tags (`?v=<name>`) — bump all of them or browsers keep the old mark:
  `frontend/index.html`, `frontend/public/manifest.webmanifest`, `frontend/src/RouterShell.tsx`,
  `frontend/src/components/firstrun/Mark.tsx`, `docs-site/astro.config.mjs`
- Docs site: `docs-site/public/favicon.svg` + its logo files; `docs-site/scripts/generate-brand-assets.mjs`
  derives the rest from `logo.svg`
- **Desktop — never hand-edit `desktop/resources/icon.*` or `trayTemplate*.png`.** They are
  GENERATED by `desktop/resources/build-onboarding.mjs` (→ `build-brand-assets.mjs`) on every build,
  so hand-replaced files are silently overwritten. The inputs are:
  - `desktop/resources/app-icon.svg` — the app icon artwork (Dock, taskbar,
    Linux). The mark is ALWAYS centred, beta or not — the BETA tag is sized (`BADGE` in
    `build-brand-assets.mjs`) to fit in the strip below the disc.
  - `desktop/resources/beta-badge.png` — the BETA tag laid under the mark from 128 px up (remove
    the `badge` option in `build-onboarding.mjs` when the beta ends)
  - `frontend/public/logo-mark.svg` — the desktop's own pages (Welcome, recovery) and the menu-bar
    tray template
  Run `node desktop/resources/build-onboarding.mjs` and commit the regenerated `icon.icns`,
  `icon.ico`, `icon.png`, `trayTemplate*.png`, `onboarding.generated.json`.
- `README.md` / `desktop/README.md` images or wording that describe the mark

**Landing page — `open-net-worth-www`** (auto-deploys on push to `main`)
- `public/`: `logo.svg`, `logo-light.svg`, `logo-mark.svg`, `logo-mark.png`, `favicon.svg`,

**Account site — `onw-cloud`** (`services/portal`; deploy only with the owner's OK, `scripts/deploy.sh --profile onw`)
- `src/onw_portal/web/templates/_logo.html` (inline mark), `src/onw_portal/static/favicon.svg`

## Traps we have hit
- **macOS caches Dock icons.** After installing a test build: `lsregister -f <app>`, `touch <app>`,
  `killall iconservicesagent Dock`. Verify the icon INSIDE the bundle
  (`iconutil -c iconset …/Contents/Resources/electron.icns`), not the Dock.
- **Mac icons sit on Apple's grid**: 824 px rounded square centred on a 1024 canvas
  (`build-brand-assets.mjs` does this). A full-bleed 1024 tile looks oversized in the Dock.
- **Grayscale sources drop colour** when composited (ImageMagick): force `-colorspace sRGB` / `PNG32:`.
- **Transparent corners look white** in image viewers; check alpha, preview on a grey background.
- **A mark on a tile fills ~66% of it** (point collar: `translate(512 512) scale(1.12)`,
  centred; the 2026-10-06 faceted disc is 75% wide at `scale(1.2)`) in every tiled file — app icon, favicons, tiled logos, touch/PWA icons, og image — so
  it matches neighbouring Dock and home-screen icons. Maskable PWA icons use `scale(1.0)` to stay
  inside the 80% safe circle; the BETA badge sits under the mark (`BADGE.top`). Stand-alone mark
  files use a viewBox cropped to the mark so small slots keep their visual weight.
- **Bump the `?v=` cache tag** on favicon/touch/manifest icon links whenever their pixels change;
  phones keep a home-screen icon from when it was added (remove and re-add it to see a new one).
- **A mark with interior cuts (faceted disc) is a `<mask>`, not black-on-white shapes**, so the
  stand-alone mark (`logo-mark.svg`, tray template, docs/portal marks) is transparent through the
  cuts and `fill`/`currentColor`/`filter:invert` still work. Inline copies (`artifact_design.py`
  `LOGO_SVG`, portal sprite in `base.html`) carry unique mask ids / one shared sprite — never
  repeat the ~6 KB path per include.
- `onboarding.generated.json` is gitignored — only the icons/tray PNGs are committed.
- **Tiny sizes (16–64 px)** stay plain; text such as BETA is unreadable there.

## Done means
1. `python3 scripts/brand_leftovers.py <old-logo.svg>` reports nothing in any repo.
2. App: `cd desktop && npm test`; front-end firstrun/sidebar suites; `lint:classes`.
   Landing: `npm run build` and `npm test` (compare failures by name with `main`).
3. Screenshots (headless, never on the owner's screen): web greeting + sidebar, desktop Welcome,
   tray, landing header + favicon, portal login — light and dark.
4. Landing live: `curl -s https://opennetworth.ai/ | grep <new cache-bust tag>`.
