# Keyboard shortcuts

Press <kbd>⌘</kbd> <kbd>Shift</kbd> <kbd>/</kbd> (Mac) or <kbd>Ctrl</kbd> <kbd>Shift</kbd>
<kbd>/</kbd> (Windows, Linux) anywhere in the app to see this list. On a Mac, use <kbd>⌘</kbd>
wherever this page says <kbd>Ctrl</kbd>.

## Anywhere

| Shortcut | What it does |
|---|---|
| <kbd>Ctrl</kbd> <kbd>K</kbd> | **Command palette** — jump to any screen, find an account, holding, category or ticker, or type a question for Lucius. |
| <kbd>Ctrl</kbd> <kbd>B</kbd> | Show or hide the sidebar. In a rich-text field it means bold instead. |
| <kbd>Ctrl</kbd> <kbd>/</kbd> | Show or hide the Lucius panel. |
| <kbd>H</kbd> | **Hide amounts** — blurs every amount on screen, handy when sharing your screen. Press again to show them. Ignored while you're typing in a field. |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>/</kbd> | Show the keyboard shortcuts. |

Hide amounts stays on after a reload until you turn it off. You can also switch it from the
sidebar footer (**Hide amounts** / **Show amounts**). Its eye icon shows the current state: an
open eye while amounts are showing, a crossed-out eye while they're hidden.

## In an account's register

Adding a transaction in the new-transaction row:

| Key | What it does |
|---|---|
| <kbd>Enter</kbd> | Move to the next field. In the amount field, save the transaction and start another. |
| <kbd>Esc</kbd> | Cancel the new row. |

With one or more transactions selected (tick their boxes):

| Key | What it does |
|---|---|
| <kbd>C</kbd> | Mark them cleared. |
| <kbd>Shift</kbd> <kbd>D</kbd> | Duplicate them. |
| <kbd>Delete</kbd> or <kbd>Backspace</kbd> | Delete them. |
| <kbd>Esc</kbd> | Close an open menu in the selection bar (move, category, memo). |

## In the Lucius chat box

| Key | What it does |
|---|---|
| <kbd>Enter</kbd> | Send. (On a phone, Enter adds a new line — tap Send instead.) |
| <kbd>Shift</kbd> <kbd>Enter</kbd> | New line. |
| <kbd>@</kbd> | Mention an account, category, holding or other item so Lucius knows exactly what you mean. See [Mentions](../lucius/mentions.md). |
| <kbd>/</kbd> | Pick a skill. See [Skills](../lucius/skills.md). |
| <kbd>↑</kbd> <kbd>↓</kbd>, then <kbd>Enter</kbd> or <kbd>Tab</kbd> | Choose from the open picker. |
| <kbd>Ctrl</kbd> <kbd>←</kbd> / <kbd>→</kbd> | Switch between the picker's sections. |
| <kbd>Esc</kbd> | Close the picker. |

## Desktop app only

The desktop app's menus add these:

| Shortcut | What it does |
|---|---|
| <kbd>Ctrl</kbd> <kbd>L</kbd> | Open Lucius. |
| <kbd>Ctrl</kbd> <kbd>N</kbd> | New transaction. |
| <kbd>Ctrl</kbd> <kbd>O</kbd> | Import a statement or receipt. |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>E</kbd> | Export your book. |
| <kbd>Ctrl</kbd> <kbd>,</kbd> | Settings. |
| <kbd>Ctrl</kbd> <kbd>1</kbd> … <kbd>8</kbd> | Go to Lucius, Assets, Accounts, Plan, Investments, Intel, Commitments, Dashboard. |
| <kbd>⌘</kbd> <kbd>[</kbd> / <kbd>⌘</kbd> <kbd>]</kbd> (Mac), <kbd>Alt</kbd> <kbd>←</kbd> / <kbd>Alt</kbd> <kbd>→</kbd> (Windows, Linux) | Back / Forward. |
| <kbd>Ctrl</kbd> <kbd>R</kbd> (also <kbd>F5</kbd> on Windows and Linux) | Reload. <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>R</kbd> force-reloads. |

Import and export aren't available while the desktop app is connected to a server rather than
a book on this computer.
